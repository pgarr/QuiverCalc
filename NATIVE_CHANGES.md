# Native Android Changes

This document tracks hand-written native Android code that lives directly in
`android/` and is **not** regenerated by `expo prebuild`. If you ever run
`expo prebuild` you must verify these changes are still in place afterwards.

> The `--clean` flag has been removed from the `prebuild` npm script for this
> reason — running with `--clean` wipes the entire `android/` folder.

---

## Training notification (persistent, always-visible buttons)

**Added in:** v1.2.0  
**Files:**

| File | Purpose |
|------|---------|
| `android/app/src/main/java/com/pgarr/quivercalc/TrainingDatabase.kt` | Opens the expo-sqlite database at `filesDir/SQLite/quivercalc.db` using Android's `SQLiteDatabase` API directly. Applies `add-N` / `score-N` actions and persists the updated progress without going through the JS bridge. |
| `android/app/src/main/java/com/pgarr/quivercalc/TrainingForegroundService.kt` | Android `Service` that runs the training as a foreground service. Builds the notification using `RemoteViews` + `NotificationCompat.DecoratedCustomViewStyle` so score buttons (`10`, `9`, `M`) or arrow buttons (`+N`) are visible in the **collapsed** notification row without the user needing to expand it. |
| `android/app/src/main/java/com/pgarr/quivercalc/TrainingNotificationReceiver.kt` | `BroadcastReceiver` for notification button presses. Updates the DB natively via `TrainingDatabase`, rebuilds the notification via `NotificationManager.notify()` (no service restart = notification shade stays open), then emits the action ID to JS for UI sync. |
| `android/app/src/main/java/com/pgarr/quivercalc/TrainingNotificationModule.kt` | React Native module (`NativeModules.TrainingNotification`) exposing `show(title, body, actionsJson)`, `update(title, body, actionsJson)`, and `stop()` to JS. Also holds the static `emitActionPress()` used by the receiver to notify JS. |
| `android/app/src/main/java/com/pgarr/quivercalc/TrainingNotificationPackage.kt` | Registers `TrainingNotificationModule` with React Native. Manually added to `MainApplication.kt` via `PackageList.apply { add(TrainingNotificationPackage()) }`. |
| `android/app/src/main/res/layout/notification_training.xml` | Custom notification layout: one body text line + a row of up to 3 `Button` views (hidden by default, shown and labelled at runtime). |

**AndroidManifest.xml changes** (in `android/app/src/main/AndroidManifest.xml`):
- `<service android:name=".TrainingForegroundService" android:foregroundServiceType="dataSync"/>`
- `<receiver android:name=".TrainingNotificationReceiver">` with intent filter for `com.pgarr.quivercalc.TRAINING_ACTION`

**MainApplication.kt change:**
```kotlin
PackageList(this).packages.apply {
    add(TrainingNotificationPackage())
}
```

**JS counterpart:** `lib/training-notification.ts` — calls `NativeModules.TrainingNotification` for show/update/stop and subscribes to `DeviceEventEmitter` for action press events.
